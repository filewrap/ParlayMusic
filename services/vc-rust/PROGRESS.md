## Bugs found during testing (fixed, rebuilt, re-verified)
1. Spotify URL parse dropped the first 2 id chars (`p + 25` on a
   23-char marker) — `4uLU6hMCjMI75M1A2tKUQC` came back as
   `LU6hMCjMI75M1A2tKUQC`. Fixed to slice by `marker.len()`; retest
   returns the full id.
2. Failed pause/resume/seek/skip on an unknown chat created (and
   persisted) an empty room via `room_mut`. Fixed to `get_mut` with a
   400 when nothing is playing; retest: state file contains only the
   real room.
