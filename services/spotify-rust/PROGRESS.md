## Bugs found during testing (fixed, rebuilt, re-verified)
1. **False positive on "Imagine":** the first wordlist flagged John
   Lennon's "Imagine" (`skip:true, matched_word:"hell"`) because the
   real LRCLib lyrics contain "No hell below us". Mild words (hell,
   damn, goddamn, crap, jesus, queer) removed from the list (60 → 54
   words); retest: `skip:false, lyrics_checked:true,
   lyrics_source:"lrclib"`. List re-verified sorted (binary_search
   depends on it) and duplicate-free.
2. **Spotify URI resolve lower-cased the id:** `spotify:playlist:
   37i9dQZF1DXcBWIGoYBM5M` came back `37i9dqzf1dxcbwigoybm5m` (ids are
   case-sensitive base62). Fixed to slice the original URL, not the
   lower-cased copy; retest returns the exact id. (The
   `open.spotify.com` branch already sliced the original URL.)
3. Empty dislike sets were persisted (`track_ids:[]` after the last
   removal). `to_json` now skips empty sets.
