## 0. Ground rules for every port worker

1. **English, normal casing, Bot API HTML.** Every ref's small-caps Unicode
   (`ᴘʟᴧʏ`, `ʜєʏ`, …) is CONVERTED to normal English. Never copy small-caps
   into Parlay. Parse mode is HTML (`<b>`, `<i>`, `<u>`, `<code>`,
   `<a href="">`, `<blockquote>`, `<blockquote expandable>`). **No TDLib-only
   rich elements:** Yukki/TgMusicBot `<h2>/<h3>/<h4>`, `<p>`, `<aside>`,
   `<footer>`, `<table>`, `<tg-button>`, `<details>/<summary>` are TRANSLATED
   to Bot API HTML on port: heading → `<b>…</b>`, table row → one plain line
   per row (`1. <a href>title</a> — requester [mm:ss]`), `<tg-button>` →
   a real inline-keyboard button with the §1 callback, `<details>` → a
   `<blockquote expandable>…</blockquote>` or a "Show more" button
   (`pl:queue:more:<chat_id>`). `<tg-spoiler>` → plain `<i>…</i>`.
   Premium-emoji `<tg-emoji>` wrappers (rustify) are dropped; the plain emoji
   is kept.
2. **One strings file.** All chosen strings live in a NEW file
   `services/core-cpp/src/ui_texts.hpp` (one `namespace ui_texts`, one
   constant per string, `{name}`/`{title}`/… placeholders). `dispatcher.cpp`
   includes it; no string literal is duplicated in a handler. Button labels
   live there too.
3. **Thumbnail rule (applies everywhere it is stated).** Now-playing, queue,
   search results, album/playlist cards and inline results use the track's
   cover URL as a **photo** with the card as caption (`sendPhoto`), falling
   back to plain text when there is no thumbnail or thumbnails are disabled
   for the chat (`/thumbnail off` / `nothumb`). Tina's `{thumb}`-in-text
   pattern is NOT ported. TGVCBot's generated 600×300 banner image is NOT
   ported (no image generation in core) — the photo rule replaces it.
4. **Progress bars.** One bar everywhere: Yukki/Arc `GetProgressBar`
   (9 stages, `◉` ball, `—` track) as a no-op button label
   `{position} {bar} {duration}`. Tina's 12-char `🔘`/`─` bar is NOT used.
5. **Callbacks: §1 namespace only.** Port workers must not invent callbacks,
   must not copy any ref's raw namespace, must not base64-encode payloads
   (ParvatiMusic) and must not JSON-serialize them (beetube, rustify).
6. **Typos are corrected, never ported** — see §27. **Foreign text is
   translated, never copied** — see §26.
7. **Hardcoded foreign bot names / URLs are dropped.** Tina's
   `https://t.me/Dollbymusicbot/room?startapp=` "Join Room" button,
   `https://yukiapi.site/file/…` image links, ParvatiMusic's
   `https://github.com/Iotatg/ParvatiMusic`, Yukki's
   `https://github.com/TheTeamVivek/YukkiMusic`, TGVCBot's
   `https://github.com/ArnabXD/TGVCBot`, Spotify-Loader's `xTeamBots` /
   `xgorn` links, lemonic's telegra.ph clone guide, Song-Downloader's
   `https://t.me/sanilaassistant_bot` ProTips links, rustify's Insightify
   link — none of these are ported. Support/updates/channel URLs come from
   Parlay config only.
8. **Gaps the inventories flagged are NOT silently filled.** TgMusicBot
   `/privacy` and `/av` handler texts were not found in that ref — Parlay
   uses the Yukki privacy page (§5) and the NoxBeats active-streams text
   instead. Arc has no `voicechat_started/ended` strings — Parlay uses
   Tina/Yukki's. Tina's `DOWNLOAD_CANCEL_BTN` has no keyboard builder in
   Tina — Parlay builds one (§8).

## 1. The ONE Parlay callback namespace

Format: `pl:<domain>:<verb>[:<arg1>[:<arg2>]]` — colon-separated, lowercase,
no spaces, no base64, no JSON. **64-byte Bot API limit is hard:** if a payload
would exceed it, use the short token form (see below), never truncate.
`<chat_id>` is the numeric chat id (negative for groups). Where a callback
needs a track, use the queue token: the first 10 hex chars of
SHA-256(track id) — exactly Yukki's `trackDeleteToken` rule (use the full id
only if it is ≤20 chars and contains no `:`). The core resolves token → track
from its current queue snapshot; an unknown/expired token is answered with
the toast `This button has expired.`

| Domain | Verbs (examples) |
|---|---|
| `pl:help:<topic>` / `pl:help:main` | `admins`, `public`, `owner`, `sudoers`, `play`, `auth`, `playlist`, `autoplay`, `restrict`, `thumb`, `start`, `bcast`, `vclogs`, `inline` |
| `pl:start` | (no verb — back to the start card) |
| `pl:player:<verb>:<chat_id>` | `pause`, `resume`, `replay`, `skip`, `stop`, `mute`, `unmute`, `seek15`, `seekback15`, `autoplay`, `thumb`, `playnow:<token>`, `addlist:<token>` |
| `pl:player:progress:<chat_id>` | no-op (progress-bar button; answers nothing / silent) |
| `pl:player:confirm:<verb>:<chat_id>` | `resume`, `unmute`, `stop` (stop-confirm row) |
| `pl:queue:more:<chat_id>` | reveal the rest of the queue |
| `pl:queue:del:<chat_id>:<token>` | delete one queued track |
| `pl:set:<key>[:<chat_id>]` | `adminmode`, `playmode`, `cmddelete`, `cleanmode`, `cleanduration`, `nothumb`, `autoplay`, `silent`, `autodelete`, `timer:<n>` |
| `pl:set:info:<key>` | alert with the setting's explainer |
| `pl:lang:select` / `pl:lang:<code>` | open picker / set language (Parlay ships English only today — the picker lists English; see §9) |
| `pl:dl:cancel:<run_id>` | cancel a download (`<run_id>` = 12 hex chars, navidrome style) |
| `pl:dl:fx:<run_id>:<effect>` | `orig`, `slow`, `nightcore`, `bass`, `8d` (tmb-rust effects, §8) |
| `pl:bcast:cancel` | cancel broadcast (owner only) |
| `pl:auth:del:<chat_id>:<user_id>` | revoke an authorized user |
| `pl:search:<n>:<req_user_id>:<track_id>` | pick search result number `n` (TGVCBot/lemonic pattern) |
| `pl:search:page:<req_user_id>:<page>:<hash>` | search pagination (Music163bot pattern; hash = FNV of query) |
| `pl:vote:<approve\|decline>:<track_id>` | queue voting (daslui pattern) |
| `pl:share:…` | see §22 — share is a link, not a callback, except `pl:share:cancel` |
| `pl:del:yes:<id>` / `pl:del:no:<id>` | delete confirm (navidrome pattern) |
| `pl:lossy:<accept\|skip>:<id>` | lossy-fallback choice (navidrome pattern) |
| `pl:restart:<bot\|replay>:<chat_id>` | restart confirm |
| `pl:close` | delete the message |
